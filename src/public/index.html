Как это работает
01

Напишите сценарий

Опишите историю в свободной форме — хоть абзац, хоть страница. ИИ сам разобьёт на сцены, напишет промпты и субтитры.

02

Одобрите кадры

ИИ генерирует изображение для каждой сцены. Просматривайте, редактируйте промпты и принимайте понравившиеся.

03

Скачайте видео

ИИ анимирует кадры, склеивает клипы и добавляет субтитры. Скачивайте MP4 — готово к публикации.

🔑 API-ключи для генерации

AnimatAI использует ваши личные API-ключи для генерации изображений и видео. Ключи хранятся только в вашем браузере и никуда не отправляются кроме соответствующих сервисов.

fal.ai — изображения и видео
1. Зайдите на fal.ai → зарегистрируйтесь
2. Перейдите в Dashboard → API Keys
3. Нажмите Add key и скопируйте ключ
OpenRouter — сценарий и изображения
1. Зайдите на openrouter.ai → зарегистрируйтесь
2. Перейдите в Keys → Create Key
3. Скопируйте ключ (начинается с sk-or-)
