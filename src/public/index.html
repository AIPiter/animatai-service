Пишете историю — ИИ разбивает на сцены, рисует кадры, оживляет и монтирует готовое видео.

Как это работает
01

Напишите сценарий

ИИ разобьёт историю на сцены, напишет промпты и субтитры для каждого кадра.

02

Генерируйте кадры

Нажмите кнопку на карточке — ИИ нарисует кадр. Пересоздавайте сколько угодно раз.

03

Скачайте видео

ИИ анимирует кадры в очереди, склеивает клипы с субтитрами в готовый MP4.

API-ключи для генерации

AnimatAI использует ваши личные API-ключи. Ключи хранятся только в вашем браузере.

fal.ai — изображения и видео
1. Зайдите на fal.ai → зарегистрируйтесь
2. Перейдите в Dashboard → API Keys → Add key
OpenRouter — сценарий и изображения
1. Зайдите на openrouter.ai → Keys → Create Key
2. Скопируйте ключ (начинается с sk-or-)
